# E-Commerce Customer Churn Analytics & Predictive Pipeline

An end-to-end Data Science and Data Engineering project that automates customer transaction data ingestion, performs feature engineering, predicts customer churn probabilities using Machine Learning, and visualizes insights via an executive Power BI dashboard.

---

## 📊 Project Overview
This project simulates a real-world corporate data pipeline. It processes e-commerce customer data, applies machine learning to identify customers who are at risk of leaving (churning), and stores predictions in a structured database connected directly to an interactive dashboard.

## 🛠️ Tech Stack & Tools
* **Language:** Python 3.x
* **Database:** SQL / SQLite
* **Libraries:** Pandas, NumPy, Scikit-Learn
* **Visualization:** Power BI Desktop

## ⚙️ Core Pipeline Architecture
1. **Data Ingestion & Cleaning:** Python scripts load raw e-commerce transaction data, handle missing values, and structure relational tables.
2. **Feature Engineering & ML:** Features are generated from user behavior, and a predictive classification model calculates real-time churn risk probabilities.
3. **Database Storage:** Processed results and predictions are structured into clean SQL tables (`customers`, `churn_predictions`).
4. **BI Dashboard:** A premium, high-impact dark-themed Power BI report visualizes total business revenue, risk distribution, and tracks top high-risk customers for the retention team.

## 📈 Dashboard Key Features
* **Executive Metrics:** Tracks overall business health and Total Revenue.
* **Churn Segmentation:** Highlights the breakdown of active vs. high-risk customers.
* **Actionable Insights:** Displays a dedicated high-risk customer table sorted by churn probability (e.g., risk > 90%) with email contacts for direct marketing interventions.
